# Demo Assets (`demos/assets`)

## Overview

Shared browser helpers, Chrome Built-in AI session adapters, WebMCP tool registration utilities, and interactive demo controllers for the 21 standalone Web AI Lab demo pages in `../` (`demos/`). Each JavaScript file executes as an IIFE loaded via `<script defer>` after `../locale-data.js`, `../i18n.js`, and `../content-data.js`, reading `document.body.dataset.demo` to hydrate the matching demo module onto `#app`.

## Interface

- `[lab.js:window.Lab]` — Shared DOM, localization, similarity, download, and Chrome Built-in AI adapter namespace attached to `window`: `{ $, $$, esc, id, topic, demo, app, status, panel, output, result, run, available, create, withSession, prompt, words, overlap, cosine, download }`.
- `[lab.js:Lab.$]` / `[lab.js:Lab.$$]` / `[lab.js:Lab.esc]` — Scoped `querySelector` / `querySelectorAll` array helpers and HTML entity escaper (`&`, `<`, `>`, `"`, `'`).
- `[lab.js:Lab.id]` / `[lab.js:Lab.topic]` / `[lab.js:Lab.demo]` / `[lab.js:Lab.app]` — Active demo slug from `document.body.dataset.demo`, matched `CONTENT_TOPICS` topic/demo metadata objects, and `#app` mount element.
- `[lab.js:Lab.status]` / `[lab.js:Lab.panel]` / `[lab.js:Lab.output]` / `[lab.js:Lab.result]` / `[lab.js:Lab.run]` — Localized `#status` updater (via `I18N.text`), panel/output HTML builders, string/JSON `#result` writer, and async click wrapper with button disablement and error capture.
- `[lab.js:Lab.available]` / `[lab.js:Lab.create]` / `[lab.js:Lab.withSession]` / `[lab.js:Lab.prompt]` — Chrome Built-in AI session lifecycle adapters over `globalThis[name]` (`LanguageModel`, `Summarizer`, `Proofreader`, `Translator`, `LanguageDetector`, `SemanticEmbedder`) injecting English-only `nativeOptions` defaults for `LanguageModel` (`expectedInputs`/`expectedOutputs` `['en']`), `Summarizer` (`type: 'key-points', format: 'plain-text', length: 'short', expectedInputLanguages: ['en'], outputLanguage: 'en'`), and `Proofreader` (`expectedInputLanguages: ['en']`), returning `'not exposed'` from `available()` when `globalThis[name]?.availability` is absent, wiring `downloadprogress` monitors, forwarding `AbortSignal`, and releasing sessions via `destroy()`.
- `[lab.js:Lab.words]` / `[lab.js:Lab.overlap]` / `[lab.js:Lab.cosine]` / `[lab.js:Lab.download]` — NFD-normalized alphanumeric word-set tokenizer, lexical Ochiai overlap scorer, equal-length vector cosine similarity function, and JSON `Blob` file downloader.
- `[lab.js:embed]` — URL query flag (`?embed=1`) and iframe check (`window.self !== window.top`) that adds `is-embedded` to `document.body.classList`.
- `[decisions.js:id]` — Mounts structured classification and abstention demos for `data-demo` slugs `issue-router`, `comment-airlock`, and `abstention-lab`.
- `[languages.js:id]` — Mounts `Translator`, `LanguageDetector`, and `Proofreader` demos for `data-demo` slugs `bilingual-relay`, `language-radar`, and `proofread-review`.
- `[lifecycle.js:id]` — Mounts availability, streaming cancellation, and cross-origin `Permissions-Policy` demos for `data-demo` slugs `model-concierge`, `stream-garden`, and `iframe-passport`.
- `[lifecycle.js:ai-policy-probe]` — Cross-window `postMessage` contract in `iframe-passport` accepting `{ kind: 'ai-policy-probe' }` payloads from `<iframe id="probe">` (`iframe-probe.html?lang=<I18N.lang>` resolved relative to `demos/`).
- `[performance.js:id]` — Mounts latency profiling (`#greedy` toggling `{ samplingMode: 'most-predictable' }`), `Summarizer` option validation, and token-budget measurement demos for `data-demo` slugs `latency-lens`, `preference-kitchen`, and `context-backpack`.
- `[recipes.js:id]` — Mounts prompt template, citation-verification, and side-by-side comparison demos for `data-demo` slugs `voice-remix`, `release-kitchen`, and `recipe-arena`.
- `[retrieval.js:id]` — Mounts `SemanticEmbedder` vs. lexical word-overlap retrieval and threshold-gated RAG demos for `data-demo` slugs `meaning-compass`, `duplicate-constellation`, and `evidence-window`.
- `[webmcp.js:id]` — Mounts WebMCP tool-registration demos for `data-demo` slugs `reading-route`, `consent-cart`, and `tool-observatory` with default tool annotations `{ readOnlyHint: false, untrustedContentHint: false, consequentialHint: false }` (`[webmcp.js:card]`).
- `[webmcp.js:webmcp]` / `[webmcp.js:forceModal]` — URL query flags where `webmcp=0` or `forceModal=1` causes `getModelContext()` to return `null` across all 3 WebMCP demos (and forces `hasWebMCP()` false to open `#webmcp-modal` on `reading-route`), while `webmcp=1` forces `hasWebMCP()` true for `reading-route` UI state without supplying a `modelContext` object to `getModelContext()`.
- `[webmcp.js:window.addToRoute]` — Global helper `(args, source = 'tool') => add(args, source)` exposed on `reading-route`; accepts `{ articleId: string }` (matching canonical IDs `models`, `browserdj`, `patterns`, `ownership` as well as case-insensitive EN/ES titles and substring aliases) and returns `{ status: 'added', article, route }`, `{ status: 'already-added', article }`, or `{ error, code: 'INVALID_ARGUMENT' | 'UNKNOWN_ARTICLE', retryable: true }`.
- `[webmcp.js:add_to_route]` — WebMCP tool registered via `(document.modelContext || navigator.modelContext).registerTool` on `reading-route` with `inputSchema` `{ type: 'object', properties: { articleId: { type: 'string' } } }` (omitting `required`).
- `[webmcp.js:request_demo_ticket_confirmation]` — Consequential WebMCP tool (`annotations.consequentialHint: true`, `required: ['quantity']`) registered on `consent-cart` validating integer `quantity` in `1..4` (returning `code: 'INVALID_QUANTITY'`, `retryable: true` otherwise) and resolving to `{ status: 'confirmed', quantity }`, `{ status: 'rejected' }`, or `{ status: 'cancelled' }`.
- `[webmcp.js:find_demo]` / `[webmcp.js:inspect_state]` — Read-only WebMCP tools registered unconditionally on `modelContext` at load in `tool-observatory` (`find_demo` requires `{ query: string }` with `readOnlyHint: true`, returning `INVALID_QUERY` or `{ matches: Array<{ id, title }> }`; `inspect_state` returns `{ time, topicCount, source: 'local-debug-state' }` with `readOnlyHint: true, debugging: true`).

## Invariants

- `[lab.js:demo]` — `lab.js` returns early before defining `window.Lab` if `document.body.dataset.demo` does not match any demo entry in `CONTENT_TOPICS`; all sibling feature scripts destructure `Lab` at load time and require a valid registered `data-demo` attribute.
- `[lab.js:demo-guide]` — Module sibling navigation (`#demo-guide`) is appended to `.intro` only when `.intro` exists, `#demo-guide` is absent, and `id !== 'reading-route'`.
- `[lab.js:run]` — Disables the clicked trigger button (`btn.disabled = true`) for the duration of the async callback and re-enables it in `finally`.
- `[lab.js:create]` / `[lab.js:withSession]` / `[lab.js:sessions]` — `create()` throws if `globalThis[name]?.create` is missing or `api.availability(opts) === 'unavailable'`; `withSession()` always invokes `session.destroy?.()` and deletes the session from `sessions` in `finally`, and `pagehide` destroys and clears any remaining tracked sessions.
- `[lab.js:cosine]` / `[lab.js:overlap]` — `cosine(a, b)` throws `'Embedding dimensions differ.'` unless both arrays are non-empty and equal length; zero-norm vectors and empty token sets return `0` rather than `NaN`.
- `[decisions.js:routeSchema]` / `[decisions.js:nativeDecision]` / `[decisions.js:comment-airlock]` / `[decisions.js:baseline]` — `nativeDecision` (`issue-router`, `abstention-lab`) enforces `{ route: 'billing' | 'technical' | 'review', reason: string }`, while `comment-airlock` enforces `{ route: 'allow' | 'review', reason: string }` (`additionalProperties: false`) and deterministic `rules()` (unconditional blank check `!text.trim()`, optional HTTP(S) URL and `> 250`-char checks) that override `finalRoute` to `'review'`; `baseline(text, margin = 1)` abstains to `'review'` when both keyword scores are `0` or `|scores.billing - scores.technical| < margin` (`#margin` slider `1..3`).
- `[languages.js:language-radar]` / `[languages.js:proofread-review]` — `language-radar` caps displayed language candidates at 8 and clamps bar widths to `[0, 100]%`; `proofread-review` validates `typeof r.correctedInput === 'string'`, rejects stale results if `#source.value` changed mid-flight, and invalidates staged corrections on input edits.
- `[lifecycle.js:model-concierge]` / `[lifecycle.js:stream]` / `[lifecycle.js:iframe-passport]` — `model-concierge` inspects all 6 Built-in AI globals (passing `{ sourceLanguage: 'es', targetLanguage: 'en' }` for `Translator`) and disables `[data-prepare]` buttons when `'unavailable'` or `'not exposed'`; `stream-garden` aborts active `AbortController` streams on cancel or `pagehide`; `iframe-passport` rejects `file:` origins, swaps ports `8080`/`8081` on both `'localhost'` and `'127.0.0.1'` (removing `allow` when `#delegate` is unchecked on loopback hosts vs. setting `allow="language-model 'none'"` on non-loopback HTTP hosts), and verifies `event.source === frame.contentWindow`, `event.data?.kind === 'ai-policy-probe'`, and exact non-opaque frame origin (`[lifecycle.js:sameOrigin]` via `Origin.from().isSameOrigin()` with `new URL()` fallback).
- `[performance.js:latency-lens]` / `[performance.js:errors]` / `[performance.js:context-backpack]` — `latency-lens` requires at least one recorded trial before exporting `{ recordedAt, configuration, userAgent, prompt, options, metrics: { setupMs, firstChunkMs, generationMs, characters, chunks, charactersPerSecond, reportedSamplingMode }, answer }`; `preference-kitchen` blocks `Summarizer.create()` when `preference === 'speed'` unless `outputLanguage === 'en'`, `type` is `'key-points'` or `'tldr'`, and `length` is `'short'` or `'medium'`; `context-backpack` throws when `session.measureContextUsage` is unavailable.
- `[recipes.js:prepare]` — `release-kitchen` requires one or more non-empty lines matching `/^R\d+:\s*\S/` with unique `R\d+` identifiers and audits generated output for missing and hallucinated `[R\d+]` tags.
- `[retrieval.js:rank]` / `[retrieval.js:duplicate-constellation]` / `[retrieval.js:evidence-window]` — `rank` embeds passages with `{ taskType: 'retrieval-document' }` and queries with `{ taskType: 'retrieval-query' }`, rejecting blank queries and mismatched counts; `duplicate-constellation` embeds up to 10 passages with `{ taskType: 'semantic-similarity' }` and clears `pairs = []` on `#add`; `evidence-window` resets `retrieved = null` (disabling `#draft`) on `#query.oninput`, forwards at most 3 passages meeting `#threshold`, and audits generated `[A]`–`[F]` citation tags against retrieved passage IDs.
- `[webmcp.js:getModelContext]` / `[webmcp.js:add]` / `[webmcp.js:prepare]` / `[webmcp.js:tool-observatory]` — `webmcp=0` and `forceModal=1` override native `modelContext`; `reading-route` rejects non-string or unrecognized `articleId` values and deduplicates `trail`; `consent-cart` enforces integer `quantity` in `1..4` and single-flight pending review (`REVIEW_PENDING`); `tool-observatory` requires non-empty `query` in `find_demo`, plain JSON object arguments in `#invoke`, and hides `debugging: true` tools in `#tools` / `#tool` UI unless `#show-debug` is checked (while keeping `inspect_state` registered on `modelContext`).

## Side Effects

- `[lab.js:window.Lab]` / `[lab.js:embed]` / `[lab.js:demo-guide]` / `[lab.js:sessions]` — Mutates `document.body.classList`, `document.documentElement` CSS `--accent`, `document.title`, `#title`, `#hook`, `#topic`, `#lesson`, and `#sources`, appends `<nav id="demo-guide">`, registers a `window` `pagehide` listener, and defines `window.Lab`.
- `[lab.js:create]` / `[lab.js:download]` — Invokes browser Built-in AI `availability()` / `create()` APIs (which can initiate on-device model downloads) and triggers client-side JSON file downloads via temporary `Blob` object URLs (`URL.createObjectURL` revoked after 2000 ms).
- `[decisions.js:app]` / `[languages.js:app]` / `[performance.js:app]` / `[recipes.js:app]` / `[retrieval.js:app]` — Hydrates `#app.innerHTML`, binds interactive event listeners, executes on-device model inference sessions, and exports `native-latency-trials.json` in `[performance.js:latency-lens]`.
- `[lifecycle.js:stream-garden]` / `[lifecycle.js:iframe-passport]` — Attaches `pagehide` and `message` listeners on `window`, runs 65 ms simulated stream timers, and dynamically sets `<iframe id="probe">` `src` (`iframe-probe.html` on ports `8080`/`8081`) and `allow` attributes.
- `[webmcp.js:register]` / `[webmcp.js:webmcp-modal]` / `[webmcp.js:copyTextToClipboard]` / `[webmcp.js:window.addToRoute]` — Hydrates `#app` and calls `modelContext.registerTool()` across WebMCP demos; specifically on `reading-route`, appends and auto-opens `<dialog id="webmcp-modal" closedby="any">` via `showModal()` when `hasWebMCP()` is false (with coordinate-checked `pointerdown`/`pointerup` light-dismiss fallback when `closedBy` is unsupported), copies `'chrome://flags'` to clipboard (`navigator.clipboard.writeText` with `document.execCommand('copy')` fallback and `#copy-flag-live` status announcements), defers `#route-toast` updates while `#webmcp-modal` is open, runs toast/badge timers, and defines `window.addToRoute`.
