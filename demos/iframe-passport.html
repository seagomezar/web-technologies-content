What this demonstrates and how to run it

Serve with npm run serve, then open http://localhost:8080. Current Chrome, eligible desktop hardware, sufficient disk space, supported languages, and model availability are required for native AI. Check the linked source for trial flags. A first model download requires a network connection. Afterward, availability can change with the browser profile and device.

SemanticEmbedder needs the reviewed Canary developer trial. Proofreader and experimental performance settings also need their respective trials. WebMCP is registered only if document.modelContext exists; local tool consoles call the same functions without claiming an agent connection. No hosted model fallback is configured.
