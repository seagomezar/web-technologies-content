# Pages

## Overview

Top-level route view components for the Koru racing coach web application, covering the marketing landing page, track overview dashboard, real-time 10Hz SSE/mock live coaching session, interactive telemetry CSV replay with predictive lookahead, and two-lap AI sector comparison, exposing explicit `[data-machine][data-state]` and `aria-busy` attributes on route containers alongside `window.__KORU_MACHINES__` registrations.

## Interface

- `[Analysis.tsx:Analysis]`: Default-exported React page component (`(props: { apiKey?: string | null }) => JSX.Element`) modeling two-lap comparison via `lap-comparison` (`'empty' | 'partial_lap1' | 'partial_lap2' -> 'ready' -> 'comparing' -> 'compared' | 'error'`), providing dual-lap CSV upload/sample loading, stacked telemetry chart comparison, and Gemini `'pro'` lap delta analysis.
- `[Dashboard.tsx:Dashboard]`: Default-exported stateless React page component (`() => JSX.Element`) rendering quick-start route cards (`/live`, `/replay`, `/analysis`), `THUNDERHILL_EAST` circuit metrics and map, and a Split-Brain coaching architecture summary.
- `[Landing.tsx:Landing]`: Default-exported stateless React marketing page component (`() => JSX.Element`) presenting hero navigation (`/dashboard`, `/live`), Split-Brain architecture pillars, workflow steps, and coach persona cards.
- `[LiveSession.tsx:LiveSession]`: Default-exported React page component (`(props: { apiKey: string | null }) => JSX.Element`) subscribing to `TelemetryStreamService`'s `telemetry-stream` machine (`'disconnected' -> 'connecting' -> 'streaming_sse' | 'replaying_file' -> 'disconnected' | 'error'`) and orchestrating gauges, track map, rolling charts, 3-path `CoachingService` coaching (`'hot'`, `'feedforward'`, `'cold'`), and TTS audio playback.
- `[Replay.tsx:Replay]`: Default-exported React page component (`(props: { apiKey: string | null }) => JSX.Element`) orchestrating explicit `replay-transport` (`'empty' -> 'paused' <-> 'playing' -> 'ended'`) and `replay-analysis` (`'idle' -> 'analyzing' -> 'ready' | 'error'`) machines, CSV/sample lap scrubbing, variable-speed timer playback, 3-path `CoachingService` coaching plus `usePredictiveCoaching` mistake-zone lookahead alerts, and windowed Gemini `'flash'` telemetry analysis.

## Invariants

- `[Analysis.tsx:Analysis]`, `[Analysis.tsx:handleFile]`, & `[Analysis.tsx:handleLoadSamples]`: Ignore change events lacking `e.target.files?.[0]`; keyboard-focusable `.visually-hidden` file inputs (`<label htmlFor>`) constrain extensions via `accept=".csv,.txt"`; uploading Lap A (`LOAD_LAP_1`), Lap B (`LOAD_LAP_2`), or sample laps (`LOAD_SAMPLES`) from ANY state (including `'compared'`, `'comparing'`, or `'error'`) deterministically transitions `lap-comparison` to `'ready'` / `'partial_lap1'` / `'partial_lap2'` / `'empty'`, increments `requestId`, and clears stale `comparisonResult` (`''`) and `error`; reflects `data-machine="lap-comparison"`, `data-state`, and `aria-busy` (during `'comparing'`) on `.page.analysis`.
- `[Analysis.tsx:handleCompare]`: Enabled only in `'ready' | 'compared' | 'error'` when both `lap1Frames.length > 0` and `lap2Frames.length > 0`; formats `MaxSpeed`/`AvgSpeed` and 20th-frame samples in `km/h` (`filter((_, i) => i % 20 === 0).slice(0, 30)`) before invoking `generateFeedback('pro', promptContext)`, guarded by `requestId` against stale mid-flight lap replacements, and caps rendered chart history at `maxPoints={500}`.
- `[Dashboard.tsx:Dashboard]`: Binds statically to `THUNDERHILL_EAST`, converts `track.length` from meters to miles via `track.length / 1609.34`, and formats lap times as `M:SS.d` in `[Dashboard.tsx:formatLapTime]`.
- `[LiveSession.tsx:LiveSession]`: Subscribes to `TelemetryStreamService` via `useSyncExternalStore` (initializing `'disconnected'`, `activeCoach = 'superaj'`, `audioEnabled = true`, `sseUrl = ''`), reflects `data-machine="telemetry-stream"`, `data-state` (`'disconnected' | 'connecting' | 'streaming_sse' | 'replaying_file' | 'error'`), and `aria-busy` (when `status === 'connecting'`) on `.page.live-session`, bounds rolling telemetry state to at most 501 frames (`[...prev.slice(-500), frame]`), and speaks coaching events only when both `audioEnabledRef.current` and `msg.text` are truthy.
- `[LiveSession.tsx:handleConnect]`: Calls `disconnect()` whenever `status === 'connected' || status === 'connecting'` (allowing users to cancel an in-flight connection cleanly via the `'Cancel'` button), otherwise connects to `sseUrl.trim() || '/mock-telemetry.txt'`.
- `[Replay.tsx:Replay]` & `[Replay.tsx:handlePlayPause]`: Initializes `replay-transport` at `'empty'` (`currentIdx = 0`, `speed = 1`), clamps playback interval delay to `Math.max(10, 100 / speed)` ms, slices chart data to `frames.slice(Math.max(0, currentIdx - 100), currentIdx + 1)`, transitions `'playing' -> 'ended'` when `currentIdx` reaches `frames.length - 1`, and when Play is pressed from `'ended'` (`totalFrames > 1`), automatically restarts from frame `0` (`'ended' -> 'playing'`) and evaluates frame `0`.
- `[Replay.tsx:loadParsedFrames]`: Deterministically dispatches `LOAD` on `replay-transport` (`-> 'paused'` or `'empty'` at `currentIdx = 0`), dispatches `RESET` on `replay-analysis` (`-> 'idle'`, clearing `result` and cancelling in-flight `requestId`), clears `messages`, and runs `analyzeLap` when `idealReference` is non-empty (`[Replay.tsx:handleLoadSample]`) or `resetPredictive()` otherwise (`[Replay.tsx:handleFileUpload]`).
- `[Replay.tsx:evaluateFrameAt]`: Exits early when `allFrames[idx]` is undefined; emits predictive lookahead alerts (`lost ${Math.abs(zone.speedDelta).toFixed(0)} km/h last lap`) with `path: 'feedforward'` and triggers TTS only when `audioEnabledRef.current` is `true`.
- `[Replay.tsx:handleAnalyze]`: Guards against `frames.length === 0` or `analysisState === 'analyzing'`, sets `aria-busy="true"` during `'analyzing'`, extracts window `frames.slice(Math.max(0, currentIdx - 100), Math.min(frames.length - 1, currentIdx + 100))` formatted in `km/h` for `generateFeedback('flash', context)`, and appends a `path: 'cold'` message only when `RESOLVE` matches the active `requestId`.

## Side Effects

- `[Analysis.tsx:handleFile]` / `[Replay.tsx:handleFileUpload]`: Reads local user-selected files asynchronously via browser `FileReader.readAsText`.
- `[Analysis.tsx:handleLoadSamples]` / `[Replay.tsx:handleLoadSample]`: Fetches static sample telemetry assets (`/sample-lap-a.csv`, `/sample-lap-b.csv`) over HTTP `fetch` and logs errors via `console.error`.
- `[Analysis.tsx:handleCompare]` / `[Replay.tsx:handleAnalyze]`: Invokes `useGeminiCloud(apiKey).generateFeedback` (`'pro'` / `'flash'`) for cloud LLM inference and registers/updates `lap-comparison` and `replay-analysis` snapshots in `window.__KORU_MACHINES__`.
- `[LiveSession.tsx:LiveSession]`: Acquires singleton `TelemetryStreamService.getInstance()`, instantiates `CoachingService` and `AudioService`, registers `telemetry-stream` and `coaching-gate` in `window.__KORU_MACHINES__` (deregistering on unmount), runs `audio.init()` on mount, subscribes to stream and coaching callbacks (triggering `useTTS.speak`), syncs `apiKey` to `CoachingService.setApiKey`, and calls `stream.disconnect()` and `audio.destroy()` on unmount.
- `[LiveSession.tsx:handleConnect]` / `[LiveSession.tsx:handleQuickPreset]`: Opens and cancels/closes SSE or mock file streams via `TelemetryStreamService.connect` and `TelemetryStreamService.disconnect`.
- `[Replay.tsx:Replay]` / `[Replay.tsx:evaluateFrameAt]`: Registers `replay-transport`, `replay-analysis`, and `coaching-gate` in `window.__KORU_MACHINES__` (deregistering on unmount), manages `setInterval`/`clearInterval` playback timers, mutates `CoachingService` state (`setApiKey`, `setCoach`, `processFrame`), updates predictive lookahead state (`checkLookahead`), and invokes `useTTS.speak`.
