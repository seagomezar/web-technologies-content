# Hooks

## Overview

Custom React 19 hooks backed by explicit finite state machines (`useMachine` / `createMachine`), encapsulating cloud LLM coaching and audio interactions (`@google/genai`), GPS distance-aligned lap delta and 8-second predictive lookahead coaching, and expressive persona text-to-speech synthesis with automatic browser Web Speech API fallback and AX inspection via `window.__KORU_MACHINES__`.

## Interface

- `[useGeminiCloud.ts:useGeminiCloud]` & `[useGeminiCloud.ts:CloudStatus]`: Exported React hook `(externalApiKey?: string | null) => { status: CloudStatus; generateFeedback: (model: CloudModel, contextString: string) => Promise<string>; generateAudio: (text: string, voiceName?: string) => Promise<Blob | null>; setApiKey: (key: string) => void; apiKey: string | null; getSnapshot: () => KoruMachineSnapshot }` where `CloudStatus` has shape `{ state: 'idle' | 'loading' | 'error' | 'success'; phase: GeminiCloudPhase; error?: string; hasKey: boolean }`.
- `[usePredictiveCoaching.ts:usePredictiveCoaching]` & `[usePredictiveCoaching.ts:PredictiveCoachingState]`: Exported React hook `() => { analyzeLap: (recentLap: TelemetryFrame[], idealLap: TelemetryFrame[]) => MistakeZone[]; checkLookahead: (currentFrame: TelemetryFrame) => MistakeZone | null; getMistakeZones: () => MistakeZone[]; getSnapshot: () => KoruMachineSnapshot; reset: () => void }` modeling `'uncalibrated' | 'armed'` lookahead state over `MistakeZone` entries (`{ distance: number; speedDelta: number; cornerName: string; advice: string }`).
- `[useTTS.ts:useTTS]` & `[useTTS.ts:TTSMachineContext]`: Exported React hook `(apiKey: string | null, coachId = 'superaj') => { provider: TTSProvider; isSpeaking: boolean; ttsPhase: TTSPhase; setProvider: (provider: TTSProvider) => void; speak: (text: string) => Promise<void> }` modeling `'idle' -> 'synthesizing_gemini' -> 'playing_audio' | 'speaking_browser_fallback' -> 'idle'` and mapping personas `'aj'`, `'rachel'`, `'tony'`, `'garmin'`, and `'superaj'` to Gemini voices (`'Fenrir'`, `'Kore'`, `'Puck'`, `'Charon'`, `'Zephyr'`), speech styles (`[useTTS.ts:PERSONA_SPEECH_STYLE]`), and browser `{ rate, pitch }` configs (`[useTTS.ts:PERSONA_BROWSER_CONFIG]`).

## Invariants

- `[useGeminiCloud.ts:useGeminiCloud]`: Models explicit `gemini-cloud` machine states `'unconfigured' | 'idle' | 'requesting_primary' | 'retrying_fallback' | 'succeeded' | 'error'` while mapping `status.state` backward-compatibly (`'unconfigured' | 'idle' -> 'idle'`, `'requesting_primary' | 'retrying_fallback' -> 'loading'`, `'succeeded' -> 'success'`, `'error' -> 'error'`); resolves `apiKey` from manual `setApiKey` override or `externalApiKey ?? localStorage.getItem('gemini_api_key') ?? null` and synchronizes `hasKey` transitions cleanly.
- `[useGeminiCloud.ts:generateFeedback]`: Requires a non-empty `effectiveKey` (`apiKey || localStorage.getItem('gemini_api_key')`), returning `''` and transitioning to `'error'` (`hasKey: false`) when absent; maps `model === 'pro'` to `'gemini-4-argon'` (`'requesting_primary'`) and `'flash'` to `'gemini-3.8-flash'`, transitioning through `'retrying_fallback'` (`'gemini-3.8-flash'`) if `'gemini-4-argon'` fails, and returning `''` on unhandled error.
- `[useGeminiCloud.ts:generateAudio]`: Defaults `voiceName` to `'Zephyr'` and audio MIME type to `'audio/wav'`; returns `null` without throwing when `effectiveKey` is missing, `interaction.output_audio?.data` is absent, or the API call fails.
- `[usePredictiveCoaching.ts:alignByDistance]`: Accumulates Haversine distance (`R = 6371000` meters) across sequential frames and buckets speeds to the nearest 5 meters (`Math.round(cumDist / 5) * 5`).
- `[usePredictiveCoaching.ts:analyzeLap]` & `[usePredictiveCoaching.ts:usePredictiveCoaching]`: Flags a `MistakeZone` at shared 5m buckets where `recentSpeed - idealSpeed < -15` (`km/h`, falling back to `` `${dist}m` `` and `` `Lost ${Math.abs(delta).toFixed(0)} km/h here` `` when no `THUNDERHILL_EAST.corners` apex lies within `< 150` m), deduplicates per `cornerName` keeping the most negative `speedDelta`, and transitions `predictive-coaching` to `'armed'` (when `zones.length > 0`) or `'uncalibrated'` (resetting `lastTriggeredCorner = null`).
- `[usePredictiveCoaching.ts:checkLookahead]`: Returns `null` immediately unless machine state is `'armed'`; converts `currentFrame.speed` from `km/h` to `m/s` (`currentFrame.speed / 3.6`), triggers only when `0 < (zone.distance - (currentFrame.distance || 0)) < (currentFrame.speed / 3.6) * 8`, and suppresses consecutive repeat alerts for the same `zone.cornerName` via `lastTriggeredCorner`.
- `[useTTS.ts:speak]`: Synchronously guards concurrent invocations via `machine.getState() !== 'idle'` (returning immediately if `!text.trim()` or non-`'idle'`) and monotonic `activeRunId`; falls back to `'Zephyr'` / `'focused motorsport coach'` / `{ rate: 1.1, pitch: 0.9 }` for unknown `coachId` values (whereas default `'superaj'` uses `'focused, confident adaptive motorsport coach'`); transitions `'synthesizing_gemini' | 'playing_audio' -> 'speaking_browser_fallback'` when `[useTTS.ts:synthesizeGeminiAudio]` or `playBlobAudio` rejects; derives `isSpeaking` strictly as `ttsPhase !== 'idle'`.
- `[useTTS.ts:synthesizeGeminiAudio]`: Throws `Error('API key required')` if `apiKey` is falsy.
- `[useTTS.ts:useTTS]`: Resolves browser speech cleanly without rejecting when `!('speechSynthesis' in window)` or `SpeechSynthesisUtterance.onerror` fires, and guarantees `URL.revokeObjectURL(url)` + `HTMLAudioElement.pause()` + `speechSynthesis.cancel()` on playback completion, playback error, AND React unmount (`CANCEL`).

## Side Effects

- `[useGeminiCloud.ts:useGeminiCloud]`, `[usePredictiveCoaching.ts:usePredictiveCoaching]`, & `[useTTS.ts:useTTS]`: Register active state-machine snapshots (`'gemini-cloud'`, `'predictive-coaching'`, `'tts-pipeline'`) in `window.__KORU_MACHINES__` on mount and deregister on unmount.
- `[useGeminiCloud.ts:useGeminiCloud]` / `[useGeminiCloud.ts:setApiKey]`: Reads, writes, and removes `localStorage` key `'gemini_api_key'`.
- `[useGeminiCloud.ts:generateFeedback]`: Issues HTTPS requests to `@google/genai` `client.interactions.create` (`'gemini-4-argon'` / `'gemini-3.8-flash'` grounded in `RACING_PHYSICS_KNOWLEDGE`) and logs failures via `console.error`.
- `[useGeminiCloud.ts:generateAudio]` / `[useTTS.ts:synthesizeGeminiAudio]`: Issues HTTPS requests to `@google/genai` (`apiVersion: 'v1beta'`) `client.interactions.create` (`'gemini-3.8-flash-lite-tts'`), decodes base64 audio payloads via `window.atob`, and logs failures via `console.error` (`[useGeminiCloud.ts:generateAudio]`, `[useTTS.ts:speak]`).
- `[useTTS.ts:useTTS]`: Allocates and revokes Blob URLs (`URL.createObjectURL` / `URL.revokeObjectURL`), plays audio through browser `HTMLAudioElement`, and invokes `window.speechSynthesis.speak` / `window.speechSynthesis.cancel` with `SpeechSynthesisUtterance`.
