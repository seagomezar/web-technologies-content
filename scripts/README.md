# scripts

## Overview

Build, localization, source-audit, deliverable-packaging, local multi-origin serving, Playwright verification, and browser autofill utilities for the Web AI Content Lab (`sebastian-gomez-web-ai-content-lab`). Python scripts compile offline locale bundles, HTML demo entry points, bilingual editorial research reports, Pillow contact sheets, CSV review tables, and portable ZIP deliverables, while Node ESM scripts inject deterministic Built-in AI / WebMCP test doubles and run automated Chromium/Chrome Canary verification suites across demos and slide decks.

## Interface

- `[native-contracts.mjs:contractDoubles]` — `export async function contractDoubles(context)`: registers a Playwright `context.addInitScript` defining browser test-double classes `LanguageModel`, `Summarizer`, `Translator`, `LanguageDetector`, `Proofreader`, and `SemanticEmbedder` (with static `availability(options)`, static `create(options)`, `destroy()`, `prompt(input, options)`, `promptStreaming(input, options)`, `summarize(input)`, `translate(input)`, `detect(input)`, `proofread(input)`, `measureContextUsage(input)`, and `embed(input, options)`), sets `document.modelContext = undefined`, and initializes `window.__calls`, `window.__created`, and `window.__destroyed`.
- `[serve.py:Handler]` / `[serve.py:servers]` — Dual-origin local static server (`npm run serve` / `python3 scripts/serve.py`, no CLI flags) serving the repository root on `127.0.0.1:8080` and `127.0.0.1:8081` with `Cache-Control: no-cache`.
- `[verify.mjs:ready]` — Primary test runner (`npm test` / `node scripts/verify.mjs`) verifying the gallery, 21 HTML demos, cross-origin `127.0.0.1:8081` iframe policy delegation, 17 `contractDoubles` workflows, `slides/index.html` layout/presenter/offline/view-transitions, optional Chrome Canary native WebMCP tools, and `./verify-keyboard.mjs`.
- `[verify-keyboard.mjs:browser]` — Standalone Playwright keyboard-navigation check (`node scripts/verify-keyboard.mjs`, also dynamically imported by `verify.mjs`) verifying `Enter` behavior on `http://localhost:8080/slides/index.html?lang=es#8.0`.
- `[verify-languages.mjs:ready]` — Standalone EN/ES localization verifier (`node scripts/verify-languages.mjs`) checking `locales/es.json` coverage, `index.html`, all 21 demos, `slides/index.html`, `slides/mockups.html`, Presenter View parity, 17 `contractDoubles` workflows in both languages, offline `file://` hash/build preservation, and Spanish research/CSV artifacts.
- `[verify-slide-code.mjs:ready]` — Standalone code-slide verifier (`node scripts/verify-slide-code.mjs`) validating all 6 code slides in `slides/index.html` across 3 viewports, executing displayed snippets via `AsyncFunction`, testing presenter focus sync and offline `file://` rendering, and optionally exercising native `document.modelContext` in Chrome Canary.
- `[verify-trustable-ai-workshop.mjs:ready]` — Standalone workshop deck verifier (`node scripts/verify-trustable-ai-workshop.mjs`) validating root `index.html?lang=en|es` workshop links, all 37 slides and build steps of `slides-trustable-ai/index.html` in ES and EN, Slide 18 live simulator controls, Presenter View step and `#clock` sync, and offline `file://` local-font + 74-PNG capture.
- `[render-slide-review.mjs:root]` — Offline Playwright screenshot generator (`node scripts/render-slide-review.mjs`) rendering final builds of all `TALK.slides.length` (20) slides in `slides/index.html` (`en` and `es`) at `1600x900`.
- `[build-locales.py:locales]` / `[build-locales.py:tr]` — CLI compiler (`python3 scripts/build-locales.py`) bundling `locales/{en,es,patterns,talk.en}.json` into `locale-data.js` (`window.LOCALES`, `window.LOCALE_PATTERNS`, `window.TALK_EN`) and translating `content-manifest.json` into `content-manifest.es.json`.
- `[build-pages.py:topics]` / `[build-pages.py:translate]` — CLI generator (`python3 scripts/build-pages.py`) evaluating `CONTENT_TOPICS` from `content-data.js` via `node` to emit standalone `demos/<demo.id>.html` pages, `content-manifest.json`, and `content-manifest.es.json`.
- `[build-research.py:judgments]` / `[build-research.py:prose_lines]` / `[build-research.py:tr]` — CLI report builder (`python3 scripts/build-research.py`) generating `research/topic-review{.md,.es.md}`, `research/link-inventory{.md,.es.md}`, and `research/row-review{.json,.es.json}` from 20 explicit row judgments and `research/source-audit.json`.
- `[build-slide-contact-sheets.py:slides]` — CLI Pillow compositor (`python3 scripts/build-slide-contact-sheets.py`) assembling `review/deck-contact-sheet-{en,es}.jpg`, `review/deck-contact-sheet.jpg`, and `review/code-contact-sheet-{en,es}.jpg` from `review/slides-{lang}/slide-*.png` and `review/code-*-{lang}.png`.
- `[build-trustable-ai-contact-sheets.py:slides]` — CLI Pillow compositor (`python3 scripts/build-trustable-ai-contact-sheets.py`) assembling 6-column contact sheets `review/trustable-ai-contact-sheet-{es,en}.jpg`.
- `[research.py:rows]` / `[research.py:fetch]` — CLI source-audit crawler (`python3 scripts/research.py`) extracting URLs from root `*.csv` plus 18 `extra` URLs, classifying URL kinds, and writing `research/source-audit.json` and `research/snapshots/<sha256[:12]>.txt`.
- `[export-guides.py:ids]` / `[export-guides.py:export]` — CLI Google Docs plain-text exporter (`python3 scripts/export-guides.py`) fetching `expert-models`, `semantic-embedder`, `mtp`, and `gemma4` into `research/snapshots/guide-<name>.txt`, updating `guide_exports` and `links` in `research/source-audit.json`, and printing exported text to stdout.
- `[repair-evidence.py:audit]` / `[repair-evidence.py:retry]` — CLI evidence recovery script (`python3 scripts/repair-evidence.py`) retrying `'fetch failed'` rows in `research/source-audit.json` via `/usr/bin/curl`.
- `[export-review-csv.py:df]` / `[export-review-csv.py:merged]` / `[export-review-csv.py:translated]` — CLI `pandas` validator and exporter (`python3 scripts/export-review-csv.py`) producing `output/spreadsheet/reviewed-topics{.csv,.es.csv}` and `review/csv-validation.json`.
- `[package-deliverables.py:files]` / `[package-deliverables.py:z]` — CLI packager (`python3 scripts/package-deliverables.py`) creating and verifying `deliverables/web-ai-content-studio.zip` (`index.html`, root scripts/manifests/READMEs, `locales/`, `demos/`, `slides/`, 11 selected `scripts/`, `research/` reports, `output/spreadsheet/` CSVs, and `review/` reports/images) with sanitized `.md`/`.json` copies and generated `BUNDLE.md`.
- `[advocu-autofill.js:SESSIONS]` / `[advocu-autofill.js:fillPage]` / `[advocu-autofill.js:setNativeValue]` / `[advocu-autofill.js:checkByLabelText]` — Self-contained browser console IIFE mounting floating UI `#advocu-autofill-panel` to autofill or copy titles, `<500` / `<1200`-character abstracts, and 8 target checkbox labels (`['Talk', 'Demo', 'Intermediate', 'Advance', 'In-person', 'Virtual', 'Up to 30 minutes', '30-60 minutes']`) for 14 EN/ES session proposals (`1-EN`..`7-ES`).
- Subdirectories: None.

## Side Effects

- `[native-contracts.mjs:contractDoubles]` — Mutates Playwright page globals `window.{LanguageModel,Summarizer,Translator,LanguageDetector,Proofreader,SemanticEmbedder}`, `window.{__calls,__created,__destroyed}`, and `document.modelContext`.
- `[serve.py:servers]` — Calls `os.chdir(root)`, binds TCP ports `127.0.0.1:8080` and `127.0.0.1:8081` in daemon threads, logs URLs to stdout, and blocks until `KeyboardInterrupt`.
- `[verify.mjs:ready]`, `[verify-keyboard.mjs:browser]`, `[verify-languages.mjs:ready]`, `[verify-slide-code.mjs:ready]`, `[verify-trustable-ai-workshop.mjs:ready]`, & `[render-slide-review.mjs:root]` — Conditionally spawn `scripts/serve.py` (where applicable), launch Playwright Chromium (`channel: 'chrome'`) and optional Chrome Canary, and write JSON verification reports and PNG screenshots under `review/`.
- `[build-locales.py:locales]`, `[build-pages.py:topics]`, & `[build-research.py:judgments]` — Overwrite `locale-data.js`, `content-manifest{.json,.es.json}`, `demos/<demo.id>.html` (spawning `node` in `build-pages.py`), and `research/{topic-review,link-inventory,row-review}*`.
- `[build-slide-contact-sheets.py:canvas]` / `[build-trustable-ai-contact-sheets.py:canvas]` — Read slide/code PNGs and `slides/assets/roboto-mono-400.ttf` and write JPEG contact sheets under `review/`.
- `[research.py:fetch]`, `[export-guides.py:export]`, & `[repair-evidence.py:retry]` — Perform outbound HTTP(S) requests (`requests` / `/usr/bin/curl`), write snapshots under `research/snapshots/`, update `research/source-audit.json`, and print guide text to stdout (`export-guides.py`).
- `[export-review-csv.py:merged]` & `[package-deliverables.py:z]` — Create `output/spreadsheet/` and `deliverables/`, writing `reviewed-topics{.csv,.es.csv}`, `review/csv-validation.json`, and `deliverables/web-ai-content-studio.zip`.
- `[advocu-autofill.js:panel]` / `[advocu-autofill.js:fillPage]` — Mounts/removes `#advocu-autofill-panel` via DOM APIs (`color-scheme: only dark`), mutates host form inputs/checkboxes/contenteditable `replaceChildren` paragraphs with synthetic `input`/`change`/`blur` events, and copies strings via `navigator.clipboard.writeText` with `document.execCommand('copy')` fallback and `#adv-status` live-region feedback.
