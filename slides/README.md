# Slides (`slides/`)

## Overview

Offline-capable, bilingual (Spanish/English) HTML slide deck runtime, speaker presenter console, and 20-slide talk specification for the WebMCP presentation. The package separates talk content, build steps, and speaker notes (`talk.js`, `full-talk.js`, `talk-i18n.js`) from viewport scaling, keyboard/touch navigation, view transitions, and dual-channel (`BroadcastChannel` + `window.postMessage`) presenter synchronization (`deck.js`, `presenter.js`), consuming root localization globals and styles (`../locale-data.js`, `../i18n.js`, `../i18n.css`).

## Interface

- **`window.deck` controller**: Public API attached by the deck IIFE exposing `{ next, previous, nextSlide, previousSlide, navigate(index, step = 0, animate = true), getState(), openPresenter(), clock(action) }` `[slides/deck.js:window.deck]`.
- **`window.TALK` specification**: Global talk payload defining `title`, `language` (default `'es'`), `plannedMinutes` (`30`), `defaults` (`{ structure, language, city }`), `sources` (`Array<{ title, url }>`), and `slides` (`Array<Slide>`, initialized with 3 opening slides in `talk.js` and extended with 17 additional slides to 20 total in `full-talk.js`) `[slides/talk.js:window.TALK]` `[slides/full-talk.js:TALK.slides.push]`.
- **Slide schema (`TALK.slides`)**: Common slide contract `{ id, kind, title, minutes, builds, notes, background? }` discriminated by `slide.kind` across `'title'` (`subtitle`, `speaker`, `photo`, `badge`), `'flow'` (`flowType: 'lanes'` with `lanes`, or `'broker'` with `sources`, `hub`, `target`, `agentComment?`; optional `flowOnly`), `'diagram'` (`subtitle?`, `diagram`), `'demo'` (`number`, `demo: 'reading-route' | 'consent-cart' | 'tool-observatory'`, `demoTitle`, `subtitle?`, `steps`), `'code'` (`subtitle`, `stepCallouts`, `codeDemo`, `code`, `codeFocus`, `codeLabel`), `'steps'` (`items: Array<{ title, body }>`), and `'statement'` (`eyebrow`, `subtitle`, `specs`, `links`) `[slides/talk.js:window.TALK.slides]` `[slides/full-talk.js:TALK.slides.push]` `[slides/deck.js:body]`.
- **`talk-i18n.js` localization pass**: Startup IIFE with no new global exports that localizes `window.TALK` in place using external globals `I18N` (`../i18n.js`) and `TALK_EN` (`../locale-data.js`) `[slides/talk-i18n.js:I18N.lang]`.
- **Keyboard shortcuts**: `deck.js` binds `ArrowRight`/`ArrowDown`/`PageDown`/`Space`/`Enter` (`next()`), `ArrowLeft`/`ArrowUp`/`PageUp`/`Backspace` (`previous()`), `Shift+ArrowRight` (`nextSlide()`), `Shift+ArrowLeft` (`previousSlide()`), `Home`/`End` (first/last slide), `P` (`openPresenter()`), `C` (`body.hide-controls`), and `F` (`toggleFullscreen()`) `[slides/deck.js:keydown]`; `presenter.js` binds `ArrowRight`/`PageDown`/`Space` (`command('next')`) and `ArrowLeft`/`PageUp` (`command('previous')`) `[slides/presenter.js:keydown]`.
- **HTML entrypoints**:
  - [index.html](./index.html) — Main 20-slide presentation entrypoint loading `../i18n.css`, `theme.css`, `deck.css`, and deferred `../locale-data.js`, `../i18n.js`, `talk.js`, `full-talk.js`, `talk-i18n.js`, and `deck.js`, providing `#viewport`, `.key-help`, `#progress`, and `.controlbar` (`#previous`, `#next`, `#presenter`, `#fullscreen[aria-pressed]`) `[slides/index.html:viewport]`.
  - [mockups.html](./mockups.html) — Opening 3-slide mockup entrypoint loading `../i18n.css`, `theme.css`, `deck.css`, setting `<body data-mockup="true">`, omitting `full-talk.js`, and providing `.mockup-label`, `#viewport`, `#progress`, and `.controlbar` (`#previous`, `#next`) `[slides/mockups.html:data-mockup]`.
  - [presenter.html](./presenter.html) — Speaker presenter console loading `../i18n.css`, `theme.css`, `presenter.css`, and deferred `../locale-data.js`, `../i18n.js`, `talk.js`, `full-talk.js`, `talk-i18n.js`, and `presenter.js`, providing `#connection[role="status"]`, `.clock` (`#wall-clock`, `#elapsed`, `#remaining`), `#position`, `inert` monitor frames `#current-preview` and `#next-preview`, `#previous`, `#next`, `#clock`, `#reset`, `#plan`, `#script[role="list"]`, `#next-title`, `#next-note`, `#sources`, and `#schedule` `[slides/presenter.html:current-preview]`.
- **URL query & hash state contracts**: Query parameters `?city=<string>` (fallback `TALK.defaults.city`), `?minutes=<number>` (fallback `TALK.plannedMinutes`), `?session=<string>` (default `'sg-webmcp-talk'`), and `?lang=<string>` (forwarded to `../i18n.js`); hash fragment `#<1-based-slide>.<0-based-step>` matching `/^#(\d+)(?:\.(\d+))?$/` `[slides/deck.js:params]` `[slides/presenter.js:params]` `[slides/deck.js:parse]`.
- **Cross-window / `BroadcastChannel` sync messages**: Deck state broadcast `{ type: 'deck-state', state: { index, step, startedAt, pausedAt, pausedMs }, slideCount, plannedMinutes, city, session }`, presenter handshake `{ type: 'presenter-ready', id }`, and remote control command `{ type: 'deck-command', command: 'next' | 'previous' | 'clock' | 'reset-clock' | 'goto', index?, step?, id }` `[slides/deck.js:announce]` `[slides/deck.js:receive]` `[slides/presenter.js:send]` `[slides/presenter.js:command]`.
- **Subdirectories & static assets**: `assets/` contains static fonts, speaker portrait, and event branding only (no source code; provenance documented in [assets/SOURCES.md](./assets/SOURCES.md)) `[slides/talk.js:window.TALK.slides]`.

## Invariants

- **Deferred script load order**: HTML entrypoints must execute `../locale-data.js` and `../i18n.js` -> `talk.js` -> (`full-talk.js` on full-deck pages) -> `talk-i18n.js` -> `deck.js` / `presenter.js`, because each downstream IIFE synchronously reads or mutates `window.TALK`, `window.TALK_EN`, and `window.I18N` during initialization `[slides/index.html:script]` `[slides/presenter.html:script]` `[slides/talk-i18n.js:I18N.lang]`.
- **Slide ID uniqueness & shallow English merge**: All 20 slide `id` values must remain distinct; when `I18N.lang === 'en'`, `talk-i18n.js` merges `TALK_EN.slides.find(s => s.id === slide.id)` via `{ ...slide, ...enSlide }`, relying on base `TALK.slides` entries to preserve non-localized fields (`kind`, `flowType`, `minutes`, `number`, `demo`) `[slides/talk-i18n.js:TALK.slides]` `[slides/full-talk.js:TALK.slides.push]`.
- **Step-to-note & code-focus alignment**: After `talk.js` joins `TALK.slides[0].notes` into a 1-element array, every slide satisfies `notes.length === builds.length + 1`, and all 6 `kind: 'code'` slides satisfy `stepCallouts.length === builds.length + 1` and `codeFocus.length === builds.length + 1` with 1-based line numbers `[slides/talk.js:TALK.slides[0].notes]` `[slides/full-talk.js:TALK.slides.push]` `[slides/deck.js:body]`.
- **Schedule budget & `?minutes` parsing**: Slide `minutes` sum to `3.5` in `talk.js` (3 slides) and `26.5` in `full-talk.js` (17 slides), totaling `30.0` to match `TALK.plannedMinutes === 30`; `deck.js` overrides `TALK.plannedMinutes` only when `Number(params.get('minutes')) > 0`, whereas `presenter.js` initializes `Number(params.get('minutes')) || TALK.plannedMinutes` until overwritten by `'deck-state'` `[slides/deck.js:planned]` `[slides/presenter.js:planned]`.
- **Mockup slice & presenter gate**: When `document.body.dataset.mockup === 'true'`, `deck.js` restricts `slides` to `TALK.slides.slice(0, 3)` and suppresses `openPresenter()` on the `P` key shortcut `[slides/deck.js:mockup]` `[slides/deck.js:keydown]`.
- **Index/step clamping & history deduplication**: `parse()` and `navigate()` clamp `index` to `[0, slides.length - 1]` and `step` to `[0, slides[index].builds.length]`, calling `history.pushState` only when `location.hash !== '#${index+1}.${step}'` `[slides/deck.js:parse]` `[slides/deck.js:navigate]`.
- **Origin verification & command deduplication**: Window `message` listeners reject messages unless `event.source === presenter` (`deck.js`) or `event.source === opener` (`presenter.js`) and require `event.origin === location.origin` whenever `location.origin !== 'null'`; `deck.js` deduplicates `deck-command` `id` values via `seenCommands` (FIFO cap of 128) and requires `Number.isInteger(message.index)` for `'goto'` `[slides/deck.js:window]` `[slides/deck.js:seenCommands]` `[slides/presenter.js:window]`.
- **Preview session isolation**: `presenter.js` namespaces `#current-preview` and `#next-preview` iframe `session` parameters as `${session}-preview-${frame.id}` to isolate preview `BroadcastChannel` instances from the active presentation session `[slides/presenter.js:preview]`.
- **Reduced motion & single flow timer**: When `matchMedia('(prefers-reduced-motion: reduce)').matches` is true, `deck.js` skips `document.startViewTransition()` and defaults the `1350ms` `flowAnim.timer` loop to paused (while `.flow-pause` allows explicit keyboard/pointer pause or play override on `'flow'` slides); at most one `flowAnim.timer` runs concurrently and any in-flight `activeTransition` is skipped upon re-navigation `[slides/deck.js:reduced]` `[slides/deck.js:syncFlowLoop]` `[slides/deck.js:navigate]`.
- **Input target, focus, & gesture guards**: `deck.js` `keydown` ignores IME composition, `Alt`/`Ctrl`/`Meta` chords, `INPUT`/`TEXTAREA`/`SELECT` targets, and `Enter`/`Space` on `a,button,summary`, while `presenter.js` `keydown` ignores IME composition, `Alt`/`Ctrl`/`Meta` chords, and `input,textarea,select,button,summary,a,[contenteditable]` targets; `navigate()` restores focus to `<article class="slide" tabindex="-1">` whenever focus was inside `#viewport` before replacement (and `paint()` shifts focus across `#previous`/`#next` when disabled at deck boundaries); viewport click-to-advance handles `.flow-pause` toggles, ignores `a,button,input,select,textarea,iframe,.demo-embed-wrap` and non-empty text selections, and scopes horizontal touch swipes (`|dx| > 45` and `|dx| > |dy| * 1.4`) via `touch-action: pan-y pinch-zoom` `[slides/deck.js:keydown]` `[slides/deck.js:navigate]` `[slides/deck.js:viewport]` `[slides/presenter.js:keydown]`.

## Side Effects

- **Global `window.TALK` creation & in-place mutation**: `talk.js` creates `window.TALK` and joins `TALK.slides[0].notes` in place; `full-talk.js` mutates `TALK.slides` via `TALK.slides.push(...)`; `talk-i18n.js` overwrites `TALK.title`, `TALK.defaults`, `TALK.slides` (or `slide.demoTitle`), and `TALK.language` in place during script load `[slides/talk.js:window.TALK]` `[slides/full-talk.js:TALK.slides.push]` `[slides/talk-i18n.js:TALK]`.
- **Deck DOM, CSS custom property, & iframe mutations**: `deck.js` defines `window.deck`, adds `body.embedded-preview` when framed (`window.self !== window.top`), toggles `body.flow-paused` from flow animation state, sets `--scale` on `documentElement` and `--slide-bg` on `body`, mutates `document.title`, `#viewport.innerHTML` (mounting `<iframe class="demo-embed-frame">` pointing to `../demos/reading-route.html` on the `'reading-route'` demo slide), and `#progress.style.width`, and injects `#slide-select` and `#step-status` into `.controlbar` `[slides/deck.js:window.deck]` `[slides/deck.js:scale]` `[slides/deck.js:paint]` `[slides/deck.js:ensureControls]`.
- **Presenter DOM & control updates**: `presenter.js` updates `#position`, `#script`, `#plan`, `#schedule` (`[data-goto]` buttons with `aria-current="true"` on the active slide), `#sources`, `#wall-clock`, `#elapsed`, `#remaining`, `.clock.overrun` (when `elapsed > planned * 60`), `#clock`, `#connection`, `#next-title`, `#next-note`, and `#next-preview` parent `.hidden`, and binds `window` (`message`, `keydown`) plus delegated `#schedule` and button `click` listeners `[slides/presenter.js:render]` `[slides/presenter.js:tick]`.
- **Browser History, View Transitions, & Fullscreen**: `deck.js` pushes `#<slide>.<step>` URLs via `history.pushState()`, invokes `document.startViewTransition({ update, types: ['forward' | 'backward' | 'step'] })` with a callback fallback when `ViewTransition.prototype.types` is absent, toggles `body.hide-controls` (`C` key), calls `requestFullscreen()` / `exitFullscreen()` (with `webkit` fallbacks) on `F` or `#fullscreen`, and syncs `#fullscreen[aria-pressed]` on `fullscreenchange` `[slides/deck.js:navigate]` `[slides/deck.js:toggleFullscreen]` `[slides/deck.js:keydown]`.
- **Cross-window `BroadcastChannel`, `postMessage`, & popup window**: `deck.js` opens `BroadcastChannel(channelName)`, posts `'deck-state'` over `BroadcastChannel` and `presenter.postMessage`, opens `presenter.html` (`'sg-webmcp-presenter'`, `1360x900`) via `window.open()`, and schedules `setTimeout(announce, 300)`; `presenter.js` opens `BroadcastChannel(session)`, posts `'presenter-ready'` and `'deck-command'` via `BroadcastChannel` and `opener.postMessage`, and sets `src`/hash on `#current-preview` and `#next-preview` iframes `[slides/deck.js:channel]` `[slides/deck.js:announce]` `[slides/deck.js:openPresenter]` `[slides/presenter.js:send]` `[slides/presenter.js:preview]`.
- **Timers & global event listeners**: `deck.js` starts/stops a `1350ms` `setInterval` (`flowAnim.timer`) on visible `'flow'` slides and binds `window` (`message`, `keydown`, `hashchange`, `popstate`, `resize`), `document` (`visibilitychange`, `fullscreenchange`, `webkitfullscreenchange`), `matchMedia('(prefers-reduced-motion: reduce)')` (`change`), and `#viewport` (`click`, `touchstart`, `touchend`) listeners; `presenter.js` starts an unconditional `500ms` `setInterval(tick, 500)` clock loop and a `3000ms` `setTimeout` disconnected-status fallback `[slides/deck.js:syncFlowLoop]` `[slides/presenter.js:tick]`.
