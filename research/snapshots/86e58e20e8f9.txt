Copilot CLI

Intro to Modern Web Guidance codelab
Discover how to guide your AI coding assistants to produce cutting-edge, interoperable web code! In this introductory codelab, you will audit a legacy web app and use the Modern Web Guidance tool to prompt agents toward modern best practices. Learn to set Baseline browser targets, optimize Core Web Vitals, and transform generic AI outputs into high-performance web solutions.
